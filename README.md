# Svpn

Svpn — приложение для трея на Windows: пускает через VPN только выбранные рабочие
программы и сайты (Фотошоп и Creative Cloud, Gemini, Claude, OpenRouter, Телеграм…),
всё остальное идёт напрямую. Внутри — Xray (VPN-движок) и sing-box (перехватчик программ).

## Установить
Скачай [`installer/Svpn-Setup-1.1.0.exe`](installer/Svpn-Setup-1.1.0.exe) и запусти.
- Windows может предупредить «Система Windows защитила ваш компьютер» — установщик не подписан:
  «Подробнее» → «Выполнить в любом случае».
- При первом запуске Windows спросит разрешение (издатель — Python Software Foundation) —
  ответь «Да»: так Svpn настраивает перехват программ.
- Вставь ссылку на свою подписку VPN в Настройках → «Сохранить и проверить».

Нужна своя подписка VPN (vless / vmess / trojan / shadowsocks / hysteria2).
Подписок, ключей и личных настроек в этом репозитории нет — они хранятся только
на компьютере пользователя (`%LOCALAPPDATA%\Svpn`).

## Обновления
Svpn проверяет `manifest.json` при запуске и раз в 6 часов. Если вышла новая версия —
в окне появляется плашка, обновление ставится одной кнопкой: качаются только изменившиеся
файлы из `files/`, каждый сверяется по sha256.

## Что где
- `src/` — исходники: `app.py` (трей, окно, сторож, обновления), `engine.py` (конфиги Xray и
  sing-box, подписки), `ui/` (окно), `build/` (сценарий установщика NSIS и скрипт выпуска).
- `files/` + `manifest.json` — текущий выпуск для автообновления.
- `installer/` — установщик.
