# Svpn

Канал обновлений Svpn — приложения для рабочего VPN команды.

Здесь лежат только файлы выпусков (`files/`) и `manifest.json` с номером версии
и контрольными суммами. Svpn сам проверяет этот файл при запуске и раз в 6 часов.
Подписок, ключей и личных настроек здесь нет — они хранятся только на компьютере
каждого пользователя.
